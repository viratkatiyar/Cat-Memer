A sleek, interactive web application that matches cat memes and animated GIFs to your exact mood! Powered by vanilla ES6+ JavaScript, glassmorphism UI design, Web Audio sound effects, confetti animations, and instant meme sharing capabilities.

---

## ✨ Features

- 🎭 **Mood-Based Meme Selection**: Choose from 9+ distinct cat emotions (`happy`, `moody`, `insomniac`, `relaxed`, `confused`, `dominant`, `hungry`, `scared`, `sad`).
- 🎞️ **Animated GIF Filter**: Toggle between static images and funny animated cat GIFs with a single click.
- 🎨 **Glassmorphic & Responsive Design**: Vibrant gradient accents, dark mode standard, backdrop blur overlay, and smooth micro-animations.
- 🔊 **Synthesized Audio Effects**: Interactive meow sound feedback using the browser's native Web Audio API (no external sound files required).
- 🎊 **Confetti Burst**: Celebrate meme generation with interactive particle canvas bursts.
- 📥 **Download & Share**: One-click meme download button, copy image link to clipboard, and instant shuffle for another meme.
- ⌨️ **Keyboard Accessibility**: Use `Esc` to close modals, `Space` or `Enter` to pick a meme, and tab navigation support.
- 🔍 **Live Search Filter**: Quickly find your desired emotion with an interactive filter input.

---

## 🛠️ Technology Stack

- **Frontend**: Semantic HTML5, Vanilla CSS3 (Custom Variables, Flexbox, CSS Grid, Glassmorphism, Animations), ES6 JavaScript Modules.
- **Audio & FX**: Native Web Audio API Synthesizer, Canvas Particle Engine.
- **Fonts & Icons**: Google Fonts (*Outfit* & *Plus Jakarta Sans*), FontAwesome Icons.

## 🚀 Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/viratkatiyar/Cat-Memer.git
   cd Cat-Memer
   ```

2. **Run locally**:
   - Open `index.html` directly in your web browser, OR
   - Serve using VS Code **Live Server** extension, OR
   - Run `npx serve .` in terminal.
