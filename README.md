# Cat Memer - Pumpkin's Purrfect Meme Picker

A sleek, interactive web application that matches cat memes and animated GIFs to your exact mood! Powered by vanilla ES6+ JavaScript, glassmorphism UI design, Web Audio sound effects, confetti animations, and instant meme sharing capabilities.


## Technology Stack

- **Frontend**: Semantic HTML5, Vanilla CSS3 (Custom Variables, Flexbox, CSS Grid, Glassmorphism, Animations), ES6 JavaScript Modules.
- **Audio & FX**: Native Web Audio API Synthesizer, Canvas Particle Engine.
- **Fonts & Icons**: Google Fonts (*Outfit* & *Plus Jakarta Sans*), FontAwesome Icons.

---

## Project Structure

```text
Cat Memer/
├── index.html        # Main HTML structure with semantic layout & modal
├── index.css         # Modern design system, themes, and glassmorphic styling
├── index.js          # Core app logic, audio FX, confetti, filter handlers
├── data.js           # Cat memes dataset (emotions, image filenames, alt tags)
├── images/           # High-resolution cat meme images and GIFs
├── .gitignore        # Version control ignore rules
└── README.md         # Project documentation & author profile
```

## Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/viratkatiyar/Cat-Memer.git
   cd Cat-Memer
   ```

2. **Run locally**:
   - Open `index.html` directly in your web browser, OR
   - Serve using VS Code **Live Server** extension, OR
   - Run `npx serve .` in terminal.
